# 08 配置与端点速查

一页纸版本，改配置/排障时只看这一张。

## 1. 数据目录

`DATA_DIR_NAME = 'our-free-model'`（`src/store.js:30`），落在 `resolveDshHome()` 下，
即 `$DSH_HOME/our-free-model/`（`DSH_HOME` 未设时退回平台默认 home）。
settings 是 **0600** 的 JSON 文件；聚合车道的第三方 key 存在该文件里，出口 API 会打码。

| 方法 | 路径 | 鉴权 | 备注 |

## 6. 三条最常见的"改了不生效"

1. **改了 `forward.port` 但没重启监听**：`config()` 每请求重读，但监听端口只在 reconcile 时重绑
   （`index.js:498-540` 的 desired/current 比较）。改端口要等一次 reconcile 或重启插件。
2. **改了 `egress.*` 但出口没变**：`egressFetch()` 只在 `egressActive()` 为真时走出口，
   且探测结果有缓存（`src/egress.js`）。改完要触发一次重新探测。
3. **改了 `tokenSaver.prompts` 但语气没变**：prompt 级改写默认全 `off`，
   且只在 `tokenSaver.enabled` 为真时生效；`rtk` 与 `prompts` 是两条独立通道。
