## 快速上手：5 分钟跑通

```bash
# 1. 已完成的 fork + clone（本机现状）
cd /home/fish/projects_mine/dsh-our-free-model
git remote -v
# origin    https://github.com/free6589/dsh-our-free-model.git   (fork)
# upstream  https://github.com/Ebony-Vinyl/dsh-our-free-model.git (原始)

# 2. 起独立网关（standalone 模式，不需要 dsh 宿主）
npm install
npm run start:standalone        # → node packages/standalone/cli.mjs

# 3. 自检（宿主侧线缆形状）
npm run selftest                # → node scripts/host-selftest.mjs

```

## 概念与模型：三条车道 + 一个网关

插件不是"一个代理"，是**三条独立车道 + 一层统一网关**，共用同一套 provider 注册：

| 车道 | 上游 | 鉴权 | 代码入口 |
| --- | --- | --- | --- |
| 免密免费车道（free lane） | `https://opencode.ai`（`/inference/v1`） | 公开凭据 `Bearer public` + 客户端指纹 | `src/upstream.js:59` `UPSTREAM_BASE` |
| 账号渠道包（channel pack） | vendored `vendor/channel-pack/pack.js`，十个账号渠道 | 各渠道自己的登录态 | `src/chan-relay.js` + `packages/standalone/channels/` |
| 协付车道（EAC）+ Kilo | EAC 服务端 + Kilo | GitHub 登录 + star 授权 | `src/eac.js` `src/eac-login.js` `src/kilo.js` |

三个核心对象：

1. **Provider route** — `ROUTE_MAIN` / `ROUTE_REGION`（`src/adapter.js` 导出，`index.js:32` 引入）。
   两个 provider 路由挂在同一个 adapter 实例上：一个给"当前出口可用"的模型，一个给"本出口被地区限制"的模型。
2. **Session** — 免费车道的配额单位。形状 `ses_` + 12 位铸造 hex + 14 位 base62
   （`SESSION_RE` `src/upstream.js:137`），且 hex 必须是**降序** `~(ms<<12|counter)`
   （`SESSION_DESCENDING_RE` `src/upstream.js:151`）。一个会话一个 session，不每次请求重铸。
3. **Forward key** — 网关自己的门禁，`ofm-` + 24 字节 base64url（`generateKey()` `src/forward.js:100`），
   与上游凭据完全解耦：调用方只拿到这个 key，包内 gateway key 不出宿主进程。

状态流转（模型可用性）：`unknown → available | region-blocked | throttled | unavailable`
（`STATE` `src/probe.js:29`），由探测循环写回 catalog，前端只读。

## 错误码表

`CODE`（`src/http.js:30-54`），与 harness 的 provider-neutral 词表对齐：

| 码 | 含义 | 触发条件 | 处理动作 |
| --- | --- | --- | --- |
| `REGION_BLOCKED` | 模型存在但该出口国家被排除 | 403 `RegionError` | 不重试，喂给可用性探测换出口 |
| `RATE_LIMIT` | 单会话配额用尽 | 429 `FreeUsageLimitError` | 不重试（换新 session 只会更糟） |
| `INVALID_CREDENTIAL` | 凭据失效 | 401/403 凭据类 | 清缓存、要求重登 |
| `AUTHORIZATION_REQUIRED` | 协付车道未授权（登录/star） | 403 协付闸门 | 前端弹登录，不清 roster |
| `LANE_LOCKED` | 客户端指纹被判死（403 FreeTierError） | 403 FreeTierError | 不可重试，属车道级拒绝 |
| `PERMISSION_DENIED` | 权限不足 | 403 其他 | 报错 |
| `QUOTA_EXHAUSTED` | 额度耗尽 | 402/429 额度类 | 报错或切车道 |
| `TRANSPORT` / `TIMEOUT` / `SERVER` / `CLIENT_ERROR` / `EMPTY_RESPONSE` / `ABORTED` | 传输层分类 | — | 按可重试性分流 |
